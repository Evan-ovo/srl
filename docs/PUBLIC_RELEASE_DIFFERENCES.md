# Public 功能与自部署

Public 提供本地优先的网页/PWA与 Android 应用，无需注册账号即可使用本地资源管理。网页、静态 APP 包和需要的中继服务均支持自行部署。

## 功能与服务范围

- 本地资源整理、预览、导入导出、备份恢复、相册与内置 APP 管理。
- 外观支持本机调色、CSS 导入/下载、预设保存与真实预览；附件增加音视频、图片缩放、代码文本与表格预览。网页与 APK 的大文件备份/恢复沿各自存储与传输适配，保留完整性校验、取消和旧版本兼容。
- 前端组件支持本地创作、编辑、导入和导出；本仓库不提供在线发布、分享链接或分享后端。
- AI/API、云盘、ImgBed、Discord 和中继服务由使用者自行配置并控制；本仓库不提供集中式账号、资源广场、公共图床或反馈后台。
- APK通过本仓库 GitHub Releases 发行，读取静态版本清单，不调用 REST API、不要求用户 Token；保留下载校验、取消与系统安装确认。
- 内置 APP 支持多选下载、内容更新和卸载，使用部署站点的静态 APP 包；第三方 APP 通过完整 `.srlapp` 包导入或更新。

完整配置与构建步骤见 [README](../README.md)。

## Worker 地址与服务

- 部署本仓库只提供网页静态资源。设备码中继和 Koofr 代理代码位于独立的 `SRL-Worker-Public` 仓库。
- 使用者 fork 并部署 `SRL-Worker-Public` 后，在网页/PWA 和 Capacitor APK 的“设置 → 中继服务”中的“自部署 Worker”填写 HTTPS 根地址，保存后点“检查连接”；设备码中继需检测通过，酒馆端须填写相同地址。独立 Kotlin APK 在“设置 → SRL Worker 地址”填写。无需在 APK 构建参数中写入中继地址。
- 该中继提供设备码、加密暂存、可选 GitHub 云备份中继和网页 Koofr 代理。Discord Bridge 保持单独的 Worker、地址和凭据设置。
- 未配置中继时，网页 GitHub 备份直连；配置后仅走自己的 Worker，失败不自动回退。网页 Koofr 中继、设备码和加密暂存在配置前不可用；APK 原生云盘直连不依赖此中继。
- APK 的 `SRL_PUBLIC_ORIGIN` / `SRL_PUBLIC_ASSET_ORIGIN` 配置的是网页/静态 APP 包站点，不是本节的独立中继地址。
- 本地开发配置、Cloudflare 账号标识和使用者凭据不得加入公开提交。

## 使用者自行配置的服务

- **Cloudflare**：部署本仓库的静态网页；部署期 Worker 功能另行从 `SRL-Worker-Public` 部署。
- **Koofr 与 WebDAV**：在应用中填写自己的服务地址与凭据；数据保存到使用者选择的云端目标。
- **Discord Bridge**：使用者部署并配置自己的 Discord Worker/Bot。它不使用通用 SRL Worker 地址。
- **ImgBed**：生图相册 → 自建图床进入独立整页，在折叠的连接设置中填写自己的 ImgBed 地址与 API Token。远端文件支持全部类型、目录/搜索/筛选、分页及页码跳转、复制直链与确认删除；列出文件需要 `list` 权限，删除需要 `delete` 权限，AUTH_CODE 仅能上传。网页需图床管理接口允许跨域。
- **AI/API**：使用者自行填写服务地址与 API Key。

## Android 公共版身份

Public 显示名称为 `SRL_Pubilc`，应用 ID 为 `app.srl.publicedition`，并保留独立图标。维护者可通过本仓库 Actions 发行独立签名 APK，使用者也可自行构建、签名和部署；配置见 README。签名密钥、密码与私人部署地址不提交源码；公开 APK 内的站点来源必须是可公开的发行地址。与其他应用迁移本地数据时，使用项目提供的备份与恢复功能。

## 隐私告知与联网选择

首次说明包含Public数据去向、具体域名、源码与托管边界；“设置 → 隐私与网络说明”可随时重看。APK自动更新检查默认关闭，需另行开启并确认当前说明版本；设置中关闭会取消正在查询的清单，不影响手动检查。此设备偏好不随通用备份恢复，也不控制网页Service Worker更新。静态站点模板关闭应用日志；部署者仍须按实际情况披露托管日志与非白名单域名，详见[隐私与发布披露](PUBLIC_PRIVACY.md)。
