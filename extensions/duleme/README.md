0.1.22：停止读取旧聊天的自动随附脚本引用；已保留资源仍可在管理脚本中手动选择，不恢复已删除资源。脚本目录只读取目录，切换来源复用当次验证结果，不顺带重渲正文。归档伴随脚本的公共库标记在父文档各保留一份，各状态栏仍独立执行依赖；不提高8 MiB上限、不截断正文或变量。显示正则每次分页统一准备，按楼层分别应用。需配套新宿主，未发布APK/网页。

替换正则直接使用当次验证得到的页面，不再重复读取；脚本未运行时修改来源或清空选择只更新管理页。正文打码每次遍历只编译一份规则，保留全部文本节点及原有打码结果。

0.1.21：启用脚本后，正文左下角提供“脚本”快捷入口。它位于阅读器控制层，小手机覆盖正文时仍可打开；选择脚本注册的“手机显隐切换”等按钮，或“停止脚本，返回正文”。停止保留单条勾选，下次可从管理脚本再次启用。按钮按当前楼层及脚本身份分开，关闭、翻楼或更换回复后不接收旧实例操作。

0.1.9 在“楼层菜单 → 变量变化回顾”查看当前回复的已保存快照与此前最近一份快照的差异，可切换上下楼、返回本楼原文或对比楼层。MVU 比较 stat_data，显示新增、移除、前后值与数值增减；普通变量对象也可比较。首次快照、缺失快照、类型不兼容分别提示；中间有楼层缺失时明确标注，不能把全部变化归因于当前楼。切换回复只读取该版本的存档，不重算后续楼层，不重放 MVU，不补猜历史值。

此功能需要 0.1.9 配套资源库宿主。打开面板才读取原件，不另存变量副本；每次最多展示 200 项差异，比较深度与节点数有界，超出明确提示。长值仅显示前 500 字，新增/删除的整组对象或数组显示项数。路径和值遵循阅读打码；不发送给 AI 或外部服务。

角色专属正则方案需要 0.1.8 配套宿主：按规则内容与来源识别，全局/预设/角色卡规则只有内容一致才复用开关，规则缺失或改变时沿用归档设置。旧版按聊天保存的开关保留，跟随默认时继续使用。远程媒体、脚本、身份打码与阅读方式仍为原有通用设置，不随角色外观自动开启；本地手选背景图片仍仅当前阅读有效，不能持久保存。

0.1.7 参考已有美化与开场白预览，补齐消息气泡和头像结构，保留聊天背景图与装饰图；酒馆排版显示角色头像，小说排版隐藏头像并保留读者字号/行距。资源库美化中的 HTTPS 字体样式按远程媒体开关加载，只提取字体定义；加载失败使用后备字体。整站布局、工具栏和底部占位不带入阅读页。横向分页禁用消息气泡的变换效果，避免分栏绘制异常；作者颜色、圆角、渐变仍保留。

聊天原件与角色关联保存在资源库；偏好、备注、进度和收藏沿用原读了么数据空间，独立列入备份/导出的“读了么”，默认勾选。卸载 APP 默认保留数据；主动清除读了么数据不会删除聊天原件。选择导出聊天时自动带上关联角色卡和配套显示正则，以便恢复阅读效果。手选正文背景图片目前只在本次打开中有效。

新收藏记住具体回复编号，切换到其它回复后，点击收藏会切回收藏的版本。旧收藏保留原摘录与楼层，不猜测此前没有记录的回复编号；原聊天变化时提示并保留摘录，不自动跳到可能错误的位置。“备用回复 → 比较两条回复”按当前正则比较两版正文，用增删标记展示差异，不运行状态栏；每版最多比较前 30000 字。

“阅读外观 → 状态栏配色”可选“保留作者配色 / 融入阅读主题”，与正文字号、行距分开。融合模式使面板背景透明，文字跟随正文实际颜色，边线使用低对比色，简化背景图、渐变及阴影；图片元素自身不改色。可以随时恢复作者配色。调整正文字号和行距不重建交互状态栏。

章节模式每次读取一楼，连续模式每批三楼；先预热下一楼的正则结果。交互面板只在当前及邻近阅读区域运行，远处面板释放脚本，返回时按归档快照重新挂载，因此临时展开/切换状态可能重置。正则结果使用有上限的内存缓存，原文、回复、规则或身份上下文变化后重新计算；缓存不保存另一份聊天原件。

阅读显示中三按钮同行，原位切换“纯净 / 精简 / 完整”：纯净只保留小说正文，去掉 HTML 状态栏、媒体和脚本，不构建或加载状态栏；只有 HTML 的楼层显示无正文提示。精简显示静态状态栏，完整可展开、收起和切换人物，不另开预览页。默认让状态栏外层背景融入阅读页，可在显示设置恢复作者背景。横向翻页时正文按一屏分栏，较长 HTML 独占可向下延伸的阅读页；在整张阅读页滚动看完，再左右翻页，不再由阅读器给面板限高或增加内部滚动。作者自身的折叠、边框和内部高度约束仍保留。横向模式使用已有翻页按钮跨章，不再让重复章末导航占出空页；上下滚动仍有章末导航。脚本只能读取当前楼层已保存的变量快照，不重放历史 MVU 更新，也不写回酒馆。打码时允许启用完整模式，切换前会提示交互状态栏保持原文、可能显示姓名；正文继续打码，图片文字不保证打码。章末导航与正文美化隔离。内置读了么短暂切后台保留阅读界面；超过现有后台释放预算后重建时恢复上次尚未主动退出的聊天和位置。

“阅读显示 → 管理显示正则”按全局、预设、角色卡分组逐条开关，选择仅保存到当前聊天，可恢复导出时设置；默认保留单条禁用及整组启用状态，按酒馆顺序执行。只重跑显示规则，不重跑已写入原文的输入/输出规则。预设来源标注为本次导出所选预设，不声称是这份旧聊天当时使用的预设。JSONL 本身不包含外部规则，旧测试记录需要通过新候选 Bridge 再次取回才能补齐。

聊天互传只复制已保存的单角色聊天，不保存、切换或删除酒馆当前聊天。重复接收不覆盖已有绑定；卡本身更新后可能形成新卡分组，可手动整理。实时传输的聊天和 PNG 不再分别限制 64/16 MiB，合成归档不超过通用单文件 256 MiB；随附正则不超过 2 MiB；暂存合计不超过 16 MiB，30 分钟过期。

本版尚不包含群聊、目录/SAF 聊天读取、历史 MVU 变量重放或外部窗口跳转。电脑测试包含真实 ST 只读导出、候选 Bridge Adapter/传输和两份实际聊天；扩展未替换到实际酒馆安装目录。实体 iOS/Android、任意外部依赖仍未验证。

设置中的“隐藏聊天记录配套正则”默认开启，只隐藏列表展示，不影响阅读、导出和备份；独立导入的普通正则不会被统一隐藏。聊天导回酒馆默认只传聊天，可选择同时传配套正则；先确认具体接收头像文件，酒馆保存新记录，配套规则作为停用的角色规则副本添加，不覆盖原规则。实时回传需 Bridge 0.3.37 的 chat-import-v1 能力；加密暂存两端也会确认目标。

聊天互传默认只保存聊天：互传设置保留“聊天记录互传携带脚本”开关，只控制角色脚本；开启时角色 PNG 内的酒馆助手脚本，与头像及角色阅读正则一起随聊天资料保存，不新增“聊天随附脚本”或完整角色卡资源。关闭携带时不保存或自动加载聊天角色脚本，实时取回与暂存领取一致；可选另存的完整角色卡原件不改写。也可选择同时保存角色卡。全局、预设脚本需用户独立导入后在“阅读显示 → 管理脚本”自行选择；总开关与单条默认关闭。新导入不再接收额外脚本来源，旧随附资源不批量删除。角色阅读脚本最多64个、规范化2 MiB，同批角色复用解析结果，源码不进入普通目录摘要；完整资源库备份保留内嵌资料，裸JSONL不包含脚本。
